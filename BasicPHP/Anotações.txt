Módulo 01: PHP basico

- Server variable: informações que o próprio servidor disponibiliza.
    -ex.: echo $_SERVER['SERVER_NAME']; vai mostrar o nome do servidor.

- print_r(): mostra o conteúdo de uma variável em formato de array.
    -ex.: print_r($_SERVER); vai mostrar todas as variáveis do servidor.
        echo '<pre>';
        print_r($_SERVER);
        echo '</pre>';
        organizando a saída em um bloco de código.

- $XXXX = ''; cria-se uma variável
    ex.: $name = 'Bernardo';
         echo $name; vai mostrar o valor da variável.

- Booleans: valores verdadeiro ou falso.
    -ex.: $isValid = true;
         echo $isValid; vai mostrar o valor da variável.

- Constants: valores que não podem ser alterados durante a execução do programa.
    -ex.: define('PI', 3.14);
         echo PI; vai mostrar o valor da constante.

- Arrays: estruturas de dados que armazenam uma coleção de valores.
    -ex.: $fruits = ['apple', 'banana', 'orange'];
         echo $fruits[0]; vai mostrar o valor do primeiro item do array.

- Concatenation: operador que une duas ou mais strings.
    -ex.: $name = 'Bernardo';
         echo 'Olá, ' . $name; vai mostrar 'Olá, Bernardo'.

- Condição: estrutura que permite executar um bloco de código apenas se uma condição for verdadeira.
    -ex.: if ($age >= 18) {
             echo 'Você é maior de idade.';
         }
         else {
             echo 'Você é menor de idade.';
         }
    -NOTA:  if (condition) {
            // code to be executed if this condition is true;
            } elseif (condition) {
            // code to be executed if first condition is false and this condition is true;
            } else {
            // code to be executed if all conditions are false;
            }

- Operadores:
            == 	| Equal | Returns true if the values are equal
            === | Identical | Returns true if the values and data types are identical
            != 	| Not equal | Returns true if the values are not equal
            <> 	| Not equal | Returns true if the values are not equal
            !== | Not identical | Returns true if the values or data types are not identical
            > 	| Greater than | Returns true if the first value is greater than the second value
            < 	| Less than  | Returns true if the first value is less than the second value
            >= 	| Greater than or equal to | Returns true if the first value is greater than, or equal to, the second value
            <= 	| Less than or equal to | Returns true if the first value is less than, or equal to, the second value
            && 	| And | True if both conditions are true
            || 	| Or  | True if either condition is true
            xor | Xor | True if either condition is true, but not both
            ! 	| Not | True if condition is not true

- Loops:
            for 	| For 	| Executes a block of code a specified number of times
            while 	| While | Queries a condition and executes a block of code while the condition is true
            do-while | Do-while | Executes a block of code once, then queries a condition and repeats the block while the condition is true
            foreach | Foreach | Iterates over each element in an array or object
            for-each | For-each | Iterates over each element in an array or object
            for-in 	| For-in | Iterates over each key/value pair in an object
            for-of 	| For-of | Iterates over each value in an iterable object
            for-await-of | For-await-of | Iterates over each value in an async iterable object
